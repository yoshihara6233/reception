THE PROBLEM

多店舗の録画運用は、
"見えない" のが当たり前になっていませんか。

本部から見ても、各店舗の NVR の状況がわからない。 止まっていても気付かない。映像を遡るのに 1 店舗ずつ電話する。 — それが、いま多くの企業で起きていることです。

PAIN ／ 01

"止まったまま" を、誰も知らない。

HDD 故障、ファン停止、PoE 異常。本部から状況を把握するすべがなく、事故が起きた時に初めて録画が止まっていたと知る — そんなケースが頻発しています。

PAIN ／ 02

機種がバラバラで、束ねられない。

i-PRO、Hikvision、Hanwha、Dahua、ONVIF 互換 — 拠点ごとに違うベンダー。それぞれ専用クライアントが必要で、横断監視のシステムを組めない。

PAIN ／ 03

新規 NVR への入替コストが膨大。

クラウド対応 NVR への全店リプレイスは数億円。費用対効果が成り立たず、現場 NVR は古いまま放置されがちです。

CAPABILITIES

3 つの原則で、現場の "目" を、束ねる。

01 ／ 既存活用

NVR を、買い替えない。

新規ハードウェアを導入せず、現在お使いの NVR のまま接続。クラウド側のアダプタが、各ベンダー固有の API を吸収します。導入初日に、ROI が成立する設計です。

02 ／ マルチベンダー

1 つの画面に、10 ベンダーを。

i-PRO・Hikvision・Hanwha・Axis・Dahua・Synology・ONVIF 互換まで、合計 10 ベンダーに正式対応。各社のライブ・録画・AI 検知を、同じ操作体験で扱えます。

03 ／ クラウドネイティブ

10,000 店舗を、スケールする。

Active-Active シャーディングと自動フェイルオーバーで、SLO 99.9% を維持。サーキットブレーカーが障害店舗を分離し、全体運用への波及を遮断します。

ARCHITECTURE

2 つの構成モードを、用途で選べる。

既存の Mini PC を活かす "各店モード" と、本部で束ねる "中央集約モード"。 混在運用も、移行も、いつでも可能です。

MODE A

各店 Mini PC モード

各店舗の Mini PC (Frigate / edge-agent) が録画とライブ配信を担当。LiveKit Cloud 経由で本部 UI に映像をストリームします。既存運用の延長で導入が容易。

店舗 NVR → edge-agent → LiveKit Cloud → Monitor UI
MODE B

中央集約 (Tier 3) モード

本部サーバ 1 台で 10,000 店舗の NVR を直接ポーリング。Mini PC 不要、初期投資ゼロ。Active-Active HA とサーキットブレーカーで大規模スケールに対応。

店舗 NVR (×10000) → Central Agent (HA) → Monitor UI
