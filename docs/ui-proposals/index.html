UI 案 5 種

レコーダ統合監視システム本部 UI のデザイン方向性。同じ機能を 5 つの異なる構造で表現しています。各カードをクリックして詳細をご確認ください。

案 1
Modern Dashboard
統計ウィジェット中心、地図は 1 パネル。Linear/Vercel 風の明るい SaaS デザイン。
案 2
Map-First Immersive
全画面の地図が主役、操作パネルがフローティング。Google Maps 風。
案 3
Split Enterprise
左: 店舗ツリー、右: 地図と詳細。情報密度が高い業務系レイアウト。
案 4
SOC Dark Wall
セキュリティオペレーションセンター風。常時暗背景・16分割が中心。
案 5
Card Gallery
地図ではなく店舗カードグリッドで一覧。スマホ画面と相性が良い軽快なデザイン。
