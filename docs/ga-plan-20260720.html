3確定した戦略（不変）

  • コア価値＝本部集中ライブ監視 + BCP。録画再生(VOD)は付加価値（防犯の生命線=録画は i-PRO NVR 本体が担う）→ VODは実機完成済みで前倒し回収。
  • 1号店=i-PRO は顧客制約（既設NVR）。SaaS GA として貫く（有償PoC扱いにしない）。
  • エッジは Frigate を1号店から外し i-PRO 直結（ONVIF/RTSP中継 + Cloudflare Tunnel）。拠点構成は3種のうち②中継ユニット（N100級・¥1.5〜3万）が本命=GAスコープ、①本部直結/③Frigate録画はGA外。
  • SLAは1号店 best-effort。録画（エッジ自律）と監視プレーン（99% SaaS）を分離定義、数値はGA後実測。
  • ロール別/テナント次元の authz 契約テスト常設は不可侵（＋7/20からUI到達smokeも常設）。
  • スケール目標: 2026/11 1店 → 2027/06 5,000店・同時最大300（代理店経由）。流通検証（代理店が売るか/支払額）は別トラックで並行。
  • 7月追記 オプション商材（巡回・発報・手荷物検査）が本番実体化 → 価格は「基本(Monitor+BCP)＋オプション」構成の検討たたき台を monitor-system-handbook.html §16 に整備。
